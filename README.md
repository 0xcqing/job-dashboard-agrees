This program sends one weird job title, which is the whole entry and nothing else. It writes that single title to `entry.txt` in the output directory and checks it is a few words of 60 characters or fewer before printing its facts.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
